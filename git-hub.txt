========================================
GIT / GITHUB - GUIA RÁPIDO
========================================


1. ENTRAR NA PASTA DO PROJETO
----------------------------------------

Entrar na pasta Desktop:

cd Desktop

Entrar na pasta do projeto:

cd ads

OU, diretamente:

cd Desktop/ads


========================================
2. CONFIGURAR MEU USUÁRIO DO GIT
========================================

Adicionar minhas variáveis no PC para validar meu acesso dentro do GitHub:

git config --global user.email "carlosgmarin749@gmail.com"

git config --global user.name "Carlos Marin"


========================================
3. INICIAR O GIT NO PROJETO
========================================

git init

- Para iniciar o projeto dentro do GitHub.

- Mas na segunda vez não é necessário, pois já criei meu projeto dentro do GitHub.


========================================
4. CONECTAR O PROJETO AO GITHUB
========================================

git remote add origin [URL HTTPS DO REPOSITÓRIO]

- Use o HTTPS, não SSH por enquanto.


========================================
5. VERIFICAR O STATUS
========================================

git status

- Para entender o que está acontecendo.


========================================
6. ADICIONAR ARQUIVOS
========================================

Adicionar todos os arquivos da pasta:

git add .

- Se usar apenas "add .", fará com todos os arquivos da pasta.


Adicionar somente uma pasta:

git add ip/

- Exemplo caso fosse para adicionar apenas uma pasta.


========================================
7. CRIAR UM COMMIT
========================================

git commit -m "descrição"

- Serve para explicar o que foi feito.

Exemplo:

git commit -m "add workspace folder"


========================================
8. BRANCH
========================================

git switch

- Para trocar a branch.


git branch -M main

- Você aqui está criando a linha de desenvolvimento independente chamada main, sua branch.


========================================
9. ENVIAR PARA O GITHUB
========================================

Primeiro envio:

git push -u origin main

- Aqui você está enviando a main para dentro do GitHub.


Depois, para subir alterações:

git add .

git commit -m "descrição"

git push

- Aqui é para subir tudo que precisa.


========================================
10. CLONAR UM PROJETO DO GITHUB
========================================

git clone https://github.com/carlosguimarin/ads.git

- Para clonar o que está no GitHub.


========================================
11. PULL
========================================

git pull

- Apenas para quando tem mais de uma branch.
